##### How to work with Poetry

1) Create a separate environment for poetry, and a separate one for the project: .venv and .venv_poetry
2) Install poetry via pip into .venv_poetry `source .venv_poetry/bin/activate; pip install poetry`
3) In the project's .venv, install the required dependencies via poetry from venv_poetry
   1) `source .venv/bin/activate; .venv_poetry/bin/poetry install --no-root`

This way, poetry's dependencies and your project's dependencies don't get mixed up. Usually, it's better to set up a shared poetry for each Python version and use it across all projects on the system.
